# Контракт HTTP API (фактический `app/main.py`)

**Транспорт:** HTTP+JSON (локальная демонстрация); `FastAPI` + `Pydantic 2`. **Swagger:** `/docs`; **OpenAPI JSON:** `/openapi.json`. Базовый адрес на Mac: `http://127.0.0.1:18000`, если в `.env` указан `API_HOST_PORT=18000`; по умолчанию внешний порт `8000`. Внутри Docker контейнер слушает `8000` независимо от внешнего порта.

## Основные маршруты

| Метод / путь | Вход | Успех | Ошибки |
|---|---|---|---|
| `POST /predict` | JSON с обязательным `text: string` | `200`, `label`, `probabilities`, `model` | `422`: некорректный/слишком длинный текст; `503`: модель не загружена; возможна `500` при непредвиденном сбое |
| `GET /health/live` | — | `200`, `{"status":"alive"}` | — |
| `GET /health/ready` | — | `200`, `{"status":"ready","model_version":"baseline"}` | `503`: модель или БД не готовы |
| `GET /healthcheck` | — | `200`, `status`, `model_loaded`, `bot_running` | — |
| `GET /model-info` | — | `200`, `model`, `classes`, `test_macro_f1`, `test_toxic_recall`, `train_rows`, `metadata_loaded` | `503` если модель не загружена |
| `GET /metrics` | — | `200`, Prometheus text exposition | Не показывается в Swagger, данные агрегированы |

**Валидация `/predict`**: поле `text` обязательно; пустая/пробельная строка, текст короче 2 символов, без букв или с более чем 40% неподдерживаемых символов отклоняется. Максимум **4096 символов** по умолчанию (`MAX_TEXT_LENGTH`). Ограничение длины проверяется в обработчике, остальные правила — Pydantic-валидатор. Список классов — `neutral`, `offensive`, `toxic`.

## Пример вызова

```bash
curl -i -X POST http://127.0.0.1:18000/predict \
  -H 'Content-Type: application/json' \
  -d '{"text":"Привет, хорошего дня!"}'
```

**Иллюстрация схемы ответа** (числа здесь *примерные*, не результат конкретного запуска):

```json
{
  "label": "neutral",
  "probabilities": {"neutral": 0.90, "offensive": 0.08, "toxic": 0.02},
  "model": "Logistic Regression"
}
```

Вероятности — числа от 0 до 1 и в норме суммируются приблизительно до 1. Возвращаемая метка соответствует максимальной вероятности. В ошибке `422` FastAPI может вернуть стандартный список `detail` с путём к полю, либо строковое `detail` при превышении лимита длины.

```bash
curl -i -X POST http://127.0.0.1:18000/predict \
  -H 'Content-Type: application/json' \
  -d '{"text":"!!!"}'
# Ожидаемый HTTP 422; точный формат detail создаёт Pydantic/FastAPI.
```

## Необходимые ограничения перед публичным доступом

- Нет аутентификации в текущей учебной версии. Порты Docker по умолчанию привязаны к `127.0.0.1`.
- Текст предсказания **сохраняется в БД** (исключение из сохранения не отменяет успешный HTTP-ответ); не отправляйте реальные персональные данные без правового основания.
- Для production нужны HTTPS, авторизация, rate limiting, журнал аудита без сырых текстов, политика удаления данных и обработка ошибочных предсказаний.
