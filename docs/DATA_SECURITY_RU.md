# Безопасность данных и секретов

- Исходный `data/dataset.txt.zip` не входит в репозиторий. Для повторного обучения необходим локальный датасет с разрешёнными правами использования; сведения о его составе приведены в [карте данных](DATA_CARD_RU.md).
- Конфигурационный файл `.env` содержит локальные пароли PostgreSQL и Grafana и при необходимости токен Telegram. В системе контроля версий используется `.env.example` без рабочих секретов.
- Артефакты `artifacts/candidate*` не публикуются автоматически и не используются сервисом без ручного продвижения. Базовая модель хранится как `artifacts/baseline_model.joblib`.
- В ноутбуках анализа и БД сохранён код без исходных табличных outputs с текстами сообщений. Отчёты `reports/` содержат агрегированные показатели и синтетические тестовые примеры.
- PostgreSQL хранит исходный текст сообщения. При внешнем внедрении необходимы права доступа, ограничение срока хранения, процедура удаления и правовая основа обработки данных.
- В Prometheus и MLflow не записываются сырые комментарии, учётные данные и идентификаторы пользователей.
- Файлы `.env`, `data/`, `mlruns/` и локальные тома БД исключены правилами `.gitignore`. Удаление уже зафиксированного секрета из рабочей директории не удаляет его из истории Git; скомпрометированные ключи подлежат замене.
