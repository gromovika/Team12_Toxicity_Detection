## Найденные проблемы и действия

1. **Конфликт внешнего порта 8000 на Mac**: первое поднятие API завершилось `Bind ... port is already allocated`. Обход — 18000. Исправление в репозитории: `API_HOST_PORT` в `.env`, поддержан Compose и `local_validate.sh`; внутри Docker всё равно `api:8000`. **Повторная проверка именно новой настройки порта на Mac пока нужна**.
2. **8 333 многометочных строк исключаются исходным парсером**, это потеря покрытия, особенно возможных пересечений оскорблений и угроз. Задокументировано; для изменения нужна новая политика разметки и новое тестирование.
3. **Несовпадение версий sklearn 1.8.0 и 1.9.1** в раннем проверочном прогоне: метрики логистической регрессии слегка отличались. Локальный повтор с pinned-зависимостями на Mac показал **равенство** кандидата baseline. Не заявлять о приросте качества.
4. **Нельзя оценить production F1 только по прогнозам**: `true_class` в БД заполняется лишь после ручной разметки. Нужно отбирать и размечать образцы, оценивать per-class показатели.
5. **Сохранение сырых текстов**: в рабочей БД присутствует персонально чувствительное содержимое; для внешнего внедрения нужны доступ, удаление, маскирование и политика хранения.
