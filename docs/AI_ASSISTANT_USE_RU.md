# Использование ИИ-ассистентов: прозрачная декларация

В проекте использовался **ChatGPT** для помощи в создании и интеграции MLOps-компонентов, технической документации и сценариев локальной диагностики. Это не заменяет самостоятельной проверки членами команды.

| Для чего использовался ИИ | Как проверяли результат | Что нельзя считать автоматически доказанным |
|---|---|---|
| Аудит структуры исходного ZIP и выявление пробелов по шести MLOps-пунктам | Сопоставление с исходным API, моделью и данными; сохранение существующих компонентов | Полная безопасность/готовность к публичному production |
| Предложение/доработка MLflow, Docker Compose, Prometheus, Grafana, двух ноутбуков | Запуск сервиса и тестов на Mac, анализ ответов и скриншотов Grafana/Prometheus, просмотр MLflow runs | Корректность каждой строки без code review и CI после публикации |
| Скрипты повторного обучения и сравнения | Реальный запуск `train-all` и `compare` с исходным датасетом, проверки соответствия sklearn и сохранённых метрик | Улучшение качества: в последнем локальном прогоне его **нет** |
| Помощь в диагностике конфликтов портов, ошибок Compose, тестов PostgreSQL | Команда выполнила команды в VS Code и предоставила вывод: 13+19 тестов passed; Prometheus UP | Автоматические нагрузочные, security и disaster-recovery тесты |
| Структурирование README, диаграмм, API-контракта, матрицы требований | Сверка содержания с исходными Python-файлами и предоставленными логами | Соответствие невложенному официальному файлу README-шаблона без его просмотра |

**Точность утверждений:** источники метрик исходного датасета — `artifacts/baseline_metadata.json`, `reports/*`, сохранённые журналы и переданные пользователем результаты локальных запусков. Некоторые ранние offline-эксперименты проведены под иной версией sklearn, это отдельно отмечено в [EXPERIMENTS_RU.md](EXPERIMENTS_RU.md).

**Ответственность команды перед сдачей:** каждый участник проверяет свою часть и может объяснить технические решения, запускает CI, сверяет фактические числа/скриншоты, подтверждает безопасность публикации. Не заявляйте независимый человеческий аудит как выполненный, если он ещё не проводился. AI-помощь и вклад участников должны быть отражены без сокрытия.
