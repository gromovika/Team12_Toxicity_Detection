## Факты об исходном baseline

- `artifacts/baseline_model.joblib` — **обычный** scikit-learn `Pipeline` (`TfidfVectorizer` + `LogisticRegression`), не словарь из нового MLOps-прототипа. Поэтому API **сохранён**, а формат кандидатов приведён к исходному.
- `baseline_metadata.json`: `seed=42`; `train_rows=167930`; `val_rows=35985`; `test_rows=35985`; `test_macro_f1=0.8571686229984659`; `test_toxic_recall=0.8803418803418803`.
- По встраиваемым в `joblib` предупреждениям sklearn модель **сериализована с версией scikit-learn 1.9.1**; поэтому окружение Docker закреплено на 1.9.1. В доступной проверке использовалась другая версия, что НЕ является подтверждением production-совместимости.
- Схема меток в исходном обучении: `NORMAL → neutral`, `INSULT/OBSCENITY → offensive`, `THREAT → toxic`. Проверку качества и обучение дополняем под эту схему.
- Основной датасет (`dataset.txt`, `dataset.txt.zip`) **не входит в ZIP**. Нет оснований заново утверждать исходные test-метрики. Для пересчёта качества требуется точный файл, совпадающий по SHA-256 с исходным `baseline_metadata.json`.
- Папка с анализом данных в ZIP имела некорректную кодировку имени; при сборке архива нормализовано `1. Анализ данных/К12_Анализ_датасетов.ipynb`.

## Фактически проверено в этой среде

- `python -m compileall` — синтаксис изменённых Python-модулей.
- `python -m pytest -q tests` — **7 пройденных новых тестов**; в них оба ноутбука исполнены на **синтетических** данных, а API проверен с заменой настоящей БД на тестовую подставку и, при отсутствии пакета, с заглушкой aiogram.
- Настоящий `baseline_model.joblib` загрузился и выдал предсказание (с предупреждением о несовпадающих версиях scikit-learn).
- Конфигурации YAML и JSON распарсены локально.

## Что НЕ проверено и что сделать перед защитой

1. **Исходные интеграционные тесты `app/tests/test_api.py` не запущены.** В локальной среде нет `aiogram`, `psycopg2`, `pgserver-extend`; установка извне невозможна. Запустить `python -m pytest -q app/tests` в подготовленном окружении.
2. **Docker-образ не собран и Compose не запущен:** отсутствует Docker Engine. Проверить `docker compose config`, `docker compose up -d --build`, `/health/ready`, `/predict`, `/metrics`, Prometheus Targets и Grafana.
3. **MLflow live-запись не проверена:** пакет и сервер в среде отсутствуют. Установить `requirements-mlops.txt`, запустить сервер и выполнить `python -m mlops.import_baseline` или обучение на реальном датасете.
4. **Качество на реальном test не пересчитано** — в загруженном архиве нет датасета. Для ноутбука `01` нужен тот же файл, из которого создан baseline (проверяется SHA-256).
5. **Нагрузочные, security и recovery-тесты** реальной инфраструктуры не проводились. Дашборды показывают метрики инференса, но не гарантируют отсутствие drift; для оценки качества в production нужны размеченные человеком данные (`true_class`).
6. **Подключение Telegram к реальному API не проверено:** нет токена и доступа к Telegram. Бот и API используют общий `ModelService`, но тесты этого интеграционного поведения только из исходного проекта.

Код готов к проверке в полноценной локальной/CI-среде. Отмеченные ограничения не следует представлять как пройденные end-to-end тесты.


## Дополнительная проверка на реальном датасете (20.11.2026)

Пользователь предоставил `dataset.txt.zip`, внутри один `dataset.txt` (248 290 строк). SHA-256 распакованного текста: `426e6bd2514fb974b68c3794da6862f5c67a34f32bdd41efeb5266a101048381`, он совпал с baseline metadata. 8 333 корректных многометочных записей исключаются исходным парсером; после очистки 239 900 уникальных записей. Разбиение train/val/test воспроизведено точно: 167 930 / 35 985 / 35 985. Проверка реальных предсказаний сохранённого baseline подтвердила Macro-F1=0.857168623, Accuracy=0.943254134, recall класса toxic=0.880341880. Сохранённые тестовые метрики соответствуют рассчитанным; это не новый эксперимент и не независимая внешняя оценка. При загрузке joblib с scikit-learn 1.8.0 возникли предупреждения, так как модель создана с 1.9.1: использовать 1.9.1 в рабочей среде. Конфиденциальные исходные строки не включены в JSON-отчёты.
