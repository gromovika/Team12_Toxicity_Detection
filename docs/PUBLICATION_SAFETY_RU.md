# Безопасность публичной версии репозитория

Этот архив подготовлен для **обсуждения и проверки перед публикацией** в GitHub. Решение о правах на данные и публикацию проекта принимает команда.

- Исходный `data/dataset.txt.zip` **не включён**. Папка `data/` исключена правилами `.gitignore`; есть агрегированная [карта данных](DATA_CARD_RU.md). Обучение на исходном датасете без него недоступно (честное ограничение публичной репродуцируемости).
- Корневой `.env` (случайные пароли PostgreSQL и Grafana, токен Telegram) **не включён**. В репозитории хранится только `.env.example` с заглушками.
- Локальные `artifacts/candidate*` (обученные модели **и их метаданные**, относящиеся к ранним локальным прогонам) исключены из ZIP и `.gitignore`: они не продвинуты в production. Сохранён доверенный `artifacts/baseline_model.joblib` для локальной демонстрации.
- Из исходных ноутбуков `1. Анализ данных/К12_Анализ_датасетов.ipynb` и `database/Toxicity_project_Database.ipynb` **удалены сохранённые outputs**: там были таблицы с примерами текстов, а также большой встроенный profiling HTML. Код и markdown ячейки сохранены. В `reports/` остаются агрегированные результаты и результаты синтетических текстовых проверок.
- В `docs/evidence/` включены **предоставленные командой скриншоты** с Prometheus UP и Grafana. Перед публичным push визуально проверьте изображения и получите согласие команды на их публикацию. Не добавляйте скриншоты с паролями, токенами, личными сообщениями и контактами.
- Не запускайте `git add -f data/`, `git add -f .env` и не публикуйте содержимое БД. Текущая база сохраняет необезличенный текст; в production необходима отдельная политика хранения и удаления.

**Проверить перед push:**

```bash
git status --short
git check-ignore -v .env data/dataset.txt.zip
# Уже после git add: убедитесь, что среди отслеживаемых файлов нет .env, data/ и сырого текста.
git diff --cached --name-only
```

**Важно:** `gitignore` не удаляет секреты, ранее добавленные в историю git. Если секрет уже был закоммичен, перевыпустите его, удалите из истории по согласованной процедуре и проверьте доступы.
